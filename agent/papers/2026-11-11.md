## 1. Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation / 编码代理内存训练后 II：通过策略蒸馏释放长期任务的预训练文件操作的内存潜力

**Date**: 2026-11-10 | **arXiv**: [2611.14009v1](http://arxiv.org/abs/2611.14009v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.14009v1)

**Categories**: cs.LG, cs.AI, cs.CL

<details><summary><b>Abstract / 摘要</b></summary>

Language-model agents increasingly tackle long-horizon tasks whose interaction histories exceed the model's active context. They must therefore decide what to write down and what to read back, and when to do either. Recent work has begun to use on-policy distillation (OPD) to make memory control part of the policy, relying on memory tools and compaction protocols that lie outside either model's pre-training. However, this weakens the distillation on both sides: the teacher cannot give useful guidance on an interface it has never used, and the student samples too few meaningful memory actions for that guidance to take effect. To study this problem, we introduce Coding Agent Memory Gym II (CAMG-II), a suite of long-horizon agentic-RL environments spanning Shop, Coding, AutoResearch, General, and Visual. Alongside each environment's native task interface, CAMG-II provides ordinary Bash access and an episode-persistent workspace, enabling the policy to create, revise, search, and reuse files as memory across context replacements. We also introduce Coding Agent Memory Post-Training II (CAMP-II), which trains a single policy jointly across all five environments with fully asynchronous OPD to learn this file-based memory behavior directly from a frozen teacher with a prior for file operations. On CAMG-II, CAMP-II obtains 2.97 times the gain of the strongest OPD baseline. The memory behavior CAMP-II learns generalizes to two external benchmarks, Terminal-Bench 2.1 and SWE-Bench Pro V2, with improved success rates.

语言模型代理越来越多地处理长期任务，其交互历史超出了模型的活动上下文。因此，他们必须决定写下什么、读回什么，以及何时做。最近的工作已经开始使用策略蒸馏（OPD）来使内存控制成为策略的一部分，依赖于任一模型预训练之外的内存工具和压缩协议。然而，这削弱了双方的提炼：教师无法在从未使用过的界面上提供有用的指导，而学生采样的有意义的记忆动作太少，指导无法生效。为了研究这个问题，我们引入了 Coding Agent Memory Gym II (CAMG-II)，这是一套涵盖 Shop、Coding、AutoResearch、General 和 Visual 的长期代理强化学习环境。除了每个环境的本机任务界面之外，CAMG-II 还提供普通的 Bash 访问和事件持久工作区，使策略能够创建、修改、搜索和重用文件作为跨上下文替换的内存。我们还引入了编码代理内存后训练 II (CAMP-II)，它通过完全异步的 OPD 在所有五个环境中联合训练单个策略，以直接从具有文件操作先验知识的冻结教师那里学习这种基于文件的内存行为。在 CAMG-II 上，CAMP-II 获得最强 OPD 基线增益的 2.97 倍。 CAMP-II 学习的内存行为可推广到两个外部基准测试：Terminal-Bench 2.1 和 SWE-Bench Pro V2，并提高了成功率。

## 2. From Attack Surface to Defense Architecture: Compositional Security for Agentic Coding Harnesses / 从攻击面到防御架构：代理编码工具的组合安全

**Date**: 2026-11-10 | **arXiv**: [2611.13960v1](http://arxiv.org/abs/2611.13960v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.13960v1)

**Categories**: cs.CR, cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

AI coding harnesses couple language models to shells, filesystems, and network sockets, turning the harness into an automated Living-off-the-Land (LotL) platform: once an adversary injects instructions into retrieved content, dual-use binaries such as bash, curl, and find become the payload. We argue that security in agentic systems is a structural property of the cognitive architecture and permission composition rather than an emergent property of individual models. Static regex blacklists miss structural evasions, whereas LLM-as-a-Judge guardrails incur high latency while over-blocking benign work.   We present ActiveSecHarness, a neurosymbolic reference-monitor architecture built around Separation of Intelligence and Authority. It combines (1) Macaroon-inspired HMAC capability tokens across four Trust and Authority Rings, (2) a 2D product taint lattice $\mathcal{L} = \mathcal{L}_{\mathrm{trust}} \times \mathcal{L}_{\mathrm{sens}}$ and a workspace provenance ledger that prevents secret laundering across disk, (3) deterministic Ring-0 OS/tool guards, and (4) bytecode certificates, split-horizon audit logs, self-healing security test synthesis, and an adaptive UserWikiManager.   Across $N=252$ fixtures ($120$ attack, $120$ benign, $12$ kill chains), a live local LLM judge (qwen3:4b) refuses $98.3\%$ of benign work at $142.3\,\mathrm{ms}$ latency, whereas Ring 0 achieves $\mathrm{ABR}=1.000$ and $\mathrm{FPR}=0.000$ in $12.7\,μ\mathrm{s}$ ($11{,}200\times$ faster). In a multi-step trajectory ablation, an oracle Conseca-style stateless policy misses $4/12$ kill chains ($\mathrm{ABR}=0.667$) and coarse Boolean taint blocks $83.3\%$ of benign workflows, while our 2D product lattice achieves $\mathrm{ABR}=1.000$ and $\mathrm{FPR}=0.000$ at $\approx 20\,μ\mathrm{s}$ per step.

AI 编码利用将语言模型与 shell、文件系统和网络套接字结合起来，将利用工具转变为自动化的 Living-off-the-Land (LotL) 平台：一旦对手将指令注入检索到的内容中，bash、curl 和 find 等双用二进制文件就会成为有效负载。我们认为，代理系统中的安全性是认知架构和权限组合的结构属性，而不是单个模型的新兴属性。静态正则表达式黑名单会错过结构性规避，而法学硕士作为法官的护栏会导致高延迟，同时过度阻止良性工作。   我们提出了 ActiveSecHarness，一种围绕智能与权威分离构建的神经符号参考监控架构。它结合了 (1) 跨四个信任和权威环的受马卡龙启发的 HMAC 功能令牌，(2) 2D 产品污点格 $\mathcal{L} = \mathcal{L}_{\mathrm{trust}} \times \mathcal{L}_{\mathrm{sens}}$ 和防止跨磁盘秘密洗钱的工作空间来源分类账，(3) 确定性 Ring-0 操作系统/工具防护，以及(4) 字节码证书、水平分割审核日志、自我修复安全测试综合以及自适应 UserWikiManager。   在 $N=252$ 固定装置中（$120$ 攻击，$120$ 良性，$12$ 杀伤链），现场本地 LLM 法官 (qwen3:4b) 在 $142.3\,\mathrm{ms}$ 延迟拒绝 $98.3\%$ 良性工作，而 Ring 0 实现 $\mathrm{ABR}=1.000$ 且$\mathrm{FPR}=0.000$，$12.7\,μ\mathrm{s}$（快$11{,}200\times$）。在多步骤轨迹消融中，Oracle Conseca 式的无状态策略错过了 $4/12$ 杀伤链 ($\mathrm{ABR}=0.667$)，并且粗略的布尔污点阻止了 $83.3\%$ 的良性工作流程，而我们的 2D 产品晶格在以下位置实现了 $\mathrm{ABR}=1.000$ 和 $\mathrm{FPR}=0.000$每步 $\approx 20\,μ\mathrm{s}$。

## 3. WAM is capable in BEHAVIOR-1K: the 2nd-place solution to the 2026 BEHAVIOR Challenge / WAM 具备 BEHAVIOR-1K 能力：2026 年行为挑战赛第二名解决方案

**Date**: 2026-11-10 | **arXiv**: [2611.13818v1](http://arxiv.org/abs/2611.13818v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.13818v1)

**Categories**: cs.RO

<details><summary><b>Abstract / 摘要</b></summary>

This work presents the 2nd-place solution (Team IF1001) to the 2026 BEHAVIOR Challenge, which evaluates mobile manipulation across 100 household tasks. Our method is built on a powerful world action model (WAM), Cosmos 3. We improve Cosmos 3 by using richer visual history, task-progress conditioning, and task-group and skill-specific LoRA adapters. During inference, we apply a separate progress estimator to supply task-progress context, and use task- and progress-conditioned routing to select a task-group or skill-specific policy, complemented by action-candidate aggregation, rolling inpainting, and task-specific temporal and gripper control. To meet the minimum inference requirement of 1 FPS, we use neither recursive self-improvement (RSI) nor agentic harness methods and rely on no closed-source models; during official private-test evaluation, our system handled concurrent requests across 100 evaluation ports with limited hardware resources, sustaining an average end-to-end inference rate above 2 FPS per port. Our method achieves a mean Q-score of 0.613 and a full-task success rate of 40.9%, averaged over 3 self-evaluation rounds across all 100 tasks. On the official private test set, with 20 instances per task, our system achieves a mean Q-score of 0.615 and a full-task success rate of 41.2%.

这项工作向 2026 年行为挑战赛展示了第二名的解决方案（Team IF1001），该挑战评估了 100 项家庭任务的移动操作。我们的方法建立在强大的世界动作模型 (WAM) Cosmos 3 之上。我们通过使用更丰富的视觉历史记录、任务进度调节以及任务组和特定于技能的 LoRA 适配器来改进 Cosmos 3。在推理过程中，我们应用单独的进度估计器来提供任务进度上下文，并使用任务和进度条件路由来选择任务组或特定于技能的策略，并辅之以动作候选聚合、滚动修复以及特定于任务的时间和夹具控制。为了满足 1 FPS 的最低推理要求，我们既不使用递归自我改进（RSI）也不使用代理利用方法，并且不依赖闭源模型；在官方私人测试评估期间，我们的系统在有限的硬件资源下处理了 100 个评估端口的并发请求，维持每个端口 2 FPS 以上的平均端到端推理速率。我们的方法实现了 0.613 的平均 Q 分数和 40.9% 的完整任务成功率，在所有 100 项任务中经过 3 轮自我评估的平均成功率。在官方私人测试集上，每个任务 20 个实例，我们的系统的平均 Q 分数为 0.615，完整任务成功率为 41.2%。

## 4. Toward Autonomous RTL and Synthesis Optimization: Benchmarking and Self-Improving Agents / 迈向自主 RTL 和综合优化：基准测试和自我改进代理

**Date**: 2026-11-10 | **arXiv**: [2611.13713v1](http://arxiv.org/abs/2611.13713v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.13713v1)

**Categories**: cs.AI, cs.AR

<details><summary><b>Abstract / 摘要</b></summary>

Recent advances in large language models (LLMs) and autonomous agents are creating new opportunities for hardware design optimization. This paper examines three connected directions toward autonomous RTL and synthesis optimization: (1) Realistic benchmarking. We discuss reference-based and open-ended RTL optimization benchmarks that evaluate optimization opportunities under realistic EDA workflows. (2) Tool-grounded RTL optimization. We present Dr. RTL, a multi-agent framework that automates critical-path analysis, RTL rewriting, and implementation-level evaluation, while continuously improving through reusable optimization skills. Evaluated on 20 real-world RTL designs, Dr.~RTL achieves average WNS/TNS improvements of 21\%/17\% with a 6\% area reduction over commercial synthesis. (3) Design-specific synthesis optimization. We explore agent-driven synthesis script tuning and the discovery of executable synthesis algorithms across intermediate representations, technology-independent optimization, and technology mapping. Finally, we envision AI-native design automation that jointly explores architectural, RTL, and EDA algorithm design spaces, guided by verification constraints and implementation feedback.

大语言模型 (LLM) 和自主代理的最新进展正在为硬件设计优化创造新的机会。本文研究了自主 RTL 和综合优化的三个相关方向：(1) 现实基准测试。我们讨论基于参考和开放式 RTL 优化基准，用于评估实际 EDA 工作流程下的优化机会。 (2) 基于工具的RTL优化。我们推出 Dr. RTL，这是一个多代理框架，可自动执行关键路径分析、RTL 重写和实施级评估，同时通过可重用的优化技能不断改进。通过对 20 个现实世界的 RTL 设计进行评估，Dr.~RTL 实现了 21%/17% 的平均 WNS/TNS 改进，与商业合成相比，面积减少了 6%。 (3) 针对设计的综合优化。我们探索代理驱动的综合脚本调整以及跨中间表示、技术无关的优化和技术映射的可执行综合算法的发现。最后，我们设想人工智能原生设计自动化，在验证约束和实施反馈的指导下，共同探索架构、RTL 和 EDA 算法设计空间。

## 5. AutoManifold: Agentic Design of Data Visualisation Algorithms via Manifold Embedding / AutoManifold：通过流形嵌入进行数据可视化算法的代理设计

**Date**: 2026-11-10 | **arXiv**: [2611.13710v1](http://arxiv.org/abs/2611.13710v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.13710v1)

**Categories**: cs.AI

**Code**: https://github.com/buraksusam/AutoManifold_NeurIPS2026.

<details><summary><b>Abstract / 摘要</b></summary>

Manifold embedding for data visualisation is dominated by a small set of hand-designed state-of-the-art (SOTA) algorithms. Their design targets are fixed at development time, resulting in inflexible algorithmic behaviour that cannot be readily steered towards user-specified structural priorities. Hand-designing new embedding algorithms to address user priority requires highly specialised expertise and is time consuming. To address autonomous algorithm design tailored to user preference, we introduce an agentic algorithm generation pipeline AutoManifold. It composes new manifold embedding algorithms from a constrained vocabulary of affinity, cost, and optimisation primitives, supported by multi-agent large-language-model (LLM) orchestration. AutoManifold conditions every stage of its design on user-specified structural preservation preferences, and iteratively refines the algorithm configuration through an LLM-guided, metric-grounded iterative loop. We compare the generated algorithms against the three strongest and most frequently used SOTA methods (t-SNE, UMAP, and PaCMAP) on real-world datasets spanning different difficulty regimes under identical evaluation infrastructure. The results demonstrate that LLM-driven, priority-conditioned algorithm synthesis can move beyond hyperparameter tuning, producing genuinely new algorithms that outperform traditional hand-designed methods in their ability to steer towards user-specified properties without compromising the intrinsic structure in the original data. The code of AutoManifold is available at https://github.com/buraksusam/AutoManifold_NeurIPS2026.

用于数据可视化的流形嵌入由一小组手工设计的最先进（SOTA）算法主导。它们的设计目标在开发时是固定的，导致算法行为不灵活，无法轻松转向用户指定的结构优先级。手工设计新的嵌入算法来解决用户优先级需要高度专业化的专业知识，并且非常耗时。为了解决根据用户偏好定制的自主算法设计，我们引入了代理算法生成管道 AutoManifold。它根据亲和力、成本和优化原语的约束词汇组成新的流形嵌入算法，并由多代理大语言模型 (LLM) 编排支持。 AutoManifold 根据用户指定的结构保留偏好来调整其设计的每个阶段，并通过 LLM 引导、基于度量的迭代循环迭代地完善算法配置。我们将生成的算法与三种最强且最常用的 SOTA 方法（t-SNE、UMAP 和 PaCMAP）在相同评估基础设施下跨越不同难度的真实数据集上进行比较。结果表明，LLM 驱动的优先级条件算法合成可以超越超参数调整，产生真正的新算法，其性能优于传统的手工设计方法，能够在不损害原始数据的内在结构的情况下转向用户指定的属性。 AutoManifold 的代码可在 https://github.com/buraksusam/AutoManifold_NeurIPS2026 获取。

<details><summary><b>Abstract / 摘要</b></summary>

As AI agents become increasingly capable of generating and optimizing hardware circuits, ensuring the correctness of AI-generated designs becomes more important. Meanwhile, advances in AI lower the barriers to developing and applying formal methods, creating new opportunities to automate and improve hardware verification. This invited paper presents an overview of the methodologies and applications of hardware formal methods in the AI era. 随着人工智能代理生成和优化硬件电路的能力越来越强，确保人工智能生成设计的正确性变得更加重要。与此同时，人工智能的进步降低了开发和应用正式方法的障碍，为自动化和改进硬件验证创造了新的机会。这篇特邀论文概述了人工智能时代硬件形式化方法的方法论和应用。首先，我们研究代理人工智能如何在三个层面上推进硬件形式化方法：规范、证明构造和推理引擎。其次，我们讨论形式化方法如何通过 RTL 生成、调试和正确性保持优化来支持可靠的人工智能驱动的硬件开发。我们回顾了代表性研究以及我们最近的贡献，强调了关键的技术进步和实验结果的见解。最后，我们讨论了证明原生硬件开发的未来研究机会，其中形式推理可能成为自主硬件设计不可或缺的一部分。

## 7. On Private Knowledge Retrieval and Private Inference for secure multi-agent systems / 安全多智能体系统的私有知识检索和私有推理

**Date**: 2026-11-10 | **arXiv**: [2611.13696v1](http://arxiv.org/abs/2611.13696v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.13696v1)

**Categories**: cs.CR, cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

Multi-agent systems provide a convenient framework for the massive deployment of agents based on Large Language Models (LLMs). It provides a sound framework where agents can interact with existing software to perform actions in an autonomous way. Agentic AI is the new term to denote these AI-based autonomous systems.   In real multi-agent systems, agents need to deal with malicious agents some of which can exploit security vulnerabilities to do harm. A memory poisoning attack is an example of exploiting a vulnerability to modify agents knowledge and, thus, affect its behavior. In an agent, there are different types of memory systems (semantic, episodic, and short-term) which have their own characteristics and for which different memory poisoning attacks may be developed.   In this paper we focus on semantic memory, we discuss its attack, and mitigation strategies. We introduce private knowledge retrieval and private inference. We propose a signature system in the knowledge base to prevent from undesired manipulation. This should avoid memory poisoning attacks by introducing security by design in the construction of the semantic memory. In our architecture, an agent contains a local Prolog-like inference system (i.e., using Horn clauses to represent knowledge) which accesses an external knowledge base to get the required knowledge. This externally signed knowledge base is accessed privately. We provide different implementations in Python using different privacy levels including k-anonymity and information-theoretical privacy (IT-PIR).

多代理系统为基于大型语言模型（LLM）的代理的大规模部署提供了便捷的框架。它提供了一个健全的框架，代理可以与现有软件交互以自主方式执行操作。代理人工智能是指这些基于人工智能的自主系统的新术语。   在真实的多代理系统中，代理需要处理恶意代理，其中一些代理可以利用安全漏洞进行危害。内存中毒攻击是利用漏洞修改代理知识并从而影响其行为的一个示例。在代理中，存在不同类型的记忆系统（语义的、情景的和短期的），它们具有各自的特征，并且可以针对这些系统开发不同的记忆中毒攻击。   在本文中，我们关注语义记忆，讨论其攻击和缓解策略。我们引入私有知识检索和私有推理。我们在知识库中提出了一个签名系统，以防止不必要的操纵。这应该通过在语义记忆的构造中引入设计安全性来避免记忆中毒攻击。在我们的架构中，代理包含一个类似于 Prolog 的本地推理系统（即使用 Horn 子句来表示知识），该系统访问外部知识库以获取所需的知识。这个外部签名的知识库是私密访问的。我们使用不同的隐私级别在 Python 中提供不同的实现，包括 k-匿名和信息理论隐私 (IT-PIR)。

## 8. DrugCoding: A Scientific Programming Agent for Drug Discovery / DrugCoding：药物发现的科学编程代理

**Date**: 2026-11-10 | **arXiv**: [2611.13651v1](http://arxiv.org/abs/2611.13651v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.13651v1)

**Categories**: cs.AI, cs.MA

<details><summary><b>Abstract / 摘要</b></summary>

Drug discovery involves multiple interconnected research stages, including molecular design, property prediction, and virtual screening. These processes are characterized by complex workflows, interdependent computational tasks, and diverse specialized tools, placing substantial demands on the coordination of scientific models and computational resources. However, existing large language model (LLM)-based scientific agents still face challenges in autonomous planning of complex tasks, adaptive selection of specialized models, and reliable execution of multi-stage scientific computations, limiting their effectiveness in automating complex drug discovery workflows. To address these challenges, we propose DrugCoding, a scientific programming agent system that integrates scientific task planning, adaptive model routing, multi-agent collaboration, and programmatic tool execution. DrugCoding enables autonomous task planning and dynamic model adaptation for complex research objectives. It can flexibly invoke specialized scientific models, autonomously generate and execute code according to task requirements, and leverage multi-agent collaboration to support efficient execution and reliable validation of complex scientific tasks. To evaluate DrugCoding's performance in scientific tool invocation and multi-stage task execution, we conduct multi-turn tool-calling experiments across diverse language models and scientific tool interfaces. ## 30. Agentic-OPD: Recovering Forgotten Agent Capabilities via On-Policy Distillation for Agentic Tasks / Agentic-OPD：通过代理任务的策略蒸馏来恢复被遗忘的代理功能

目的：估计使用大语言模型 (LLM) 工具的代理在模拟放射学文档中记录临床相关的虚假或不受支持的信息的频率，以及在每次操作之前应用了多少保障措施来减少这些错误。   材料和方法：在这项模拟研究（2026 年 10 月）中，48 个综合的、放射科医生审查的基本场景涵盖了寻找沟通、肿瘤板准备和后续管理。 43 个还存在误导性信息变体（91 个变体）。六个 LLM 代理（Claude Sonnet 5.5、GPT-6.1-Sol、GLM-5.3、MiniMax M3、Gemma-4-31B、Qwen3.8-27B）仅使用权限、确定性规则和规则加上本地运行的 LLM 检查器（1638 集）完成了每个变体。主要结果是每集至少执行一次高度严重的违规行为。在基本场景级别评估每个代理的风险差异，并探索性地跨代理进行汇总，并分析文档访问和阻止。   结果：仅在获得许可的情况下，7.3%-27.1% 的事件存在高严重性违规（跨代理汇总为 19.4%）。总体而言，使用规则的率为 16.7%（-2.8 个百分点；95% CI：-6.1，0.5），使用规则加 LLM 检查器的率为 13.2%（-6.2；95% CI：-9.5，-3.0）。将 LLM 检查器添加到规则中将其更改为 -3.5（95% CI：-6.3，-0.7）。没有检测到代理之间存在差异（P = .43），并且任务成功率没有明显下降。在误导性变体中，特工在 83% 的事件中打开了修改后的文档，无论错误如何，并且 58% 的错误陈述引用了该文档。大多数被阻止的操作 (64%-68%) 不会造成违规，并会被退回进行修改。   结论：分层保护措施减少了，但未能防止高严重性错误。误导性信息产生的错误反映的是错误判断，而不是遗漏信息。

## 45. ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping / ScrapeBench：评估人工智能代理在网站抓取中的法律合规性

**Date**: 2026-11-08 | **arXiv**: [2611.11306v2](http://arxiv.org/abs/2611.11306v2) | **PDF**: [Link](http://arxiv.org/pdf/2611.11306v2)

**Categories**: cs.CL, cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

AI agents deployed on the open web are becoming more capable of performing actions that may breach contractual provisions and violate computer security laws. In this paper, we introduce ScrapeBench, the first agentic benchmark for empirically evaluating the legal compliance of AI agents with website scraping policies, namely terms of service (ToS) and $\texttt{robots.txt}$ directives. Across widely used closed-weight and open-weight AI agents, we find that most agents exhibit low compliance rates (< 5%) when instructed to scrape websites in our sample of 1,626 popular websites that explicitly prohibit scraping. In addition, we observe that even where AI agents actively check the applicable ToS and $\texttt{robots.txt}$, they continue to exhibit low compliance rates. Conversely, in our sample of 269 websites that do not prohibit scraping, we observe that agents sometimes refuse to scrape despite it being lawful, such as Claude Opus 4.6 exhibiting an over-refusal rate of 98.5%. Our human baseline experiments (n = 180 participants) suggest that humans exhibit compliance rates comparable to AI agents but over-refuse at much higher rates.

部署在开放网络上的人工智能代理正在变得更有能力执行可能违反合同条款和计算机安全法的行动。在本文中，我们介绍了 ScrapeBench，这是第一个代理基准，用于根据网站抓取策略（即服务条款（ToS）和 $\texttt{robots.txt}$ 指令）实证评估人工智能代理的法律合规性。在广泛使用的封闭权重和开放权重 AI 代理中，我们发现，在我们的 1,626 个明确禁止抓取的热门网站样本中，大多数代理在被指示抓取网站时表现出较低的合规率 (< 5%)。此外，我们观察到，即使人工智能代理主动检查适用的 ToS 和 $\texttt{robots.txt}$，他们的合规率仍然很低。相反，在我们的 269 个不禁止抓取的网站样本中，我们观察到代理有时会拒绝抓取，尽管它是合法的，例如 Claude Opus 4.6 的过度拒绝率高达 98.5%。我们的人类基线实验（n = 180 名参与者）表明，人类表现出与人工智能代理相当的合规率，但过度拒绝率要高得多。
