## 1. Policy Search in Code Space for Multi-Agent Pathfinding / 代码空间中的策略搜索用于多代理寻路

**Date**: 2026-10-19 | **arXiv**: [2610.25946v1](http://arxiv.org/abs/2610.25946v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25946v1)

**Categories**: cs.RO, cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

Developing coordination policies for complex multi-agent systems relies on either labor-intensive algorithm design or opaque task-specific reinforcement learning. With recent advances in autonomous coding agents, we show that policy search directly in code space offers a compelling third path that combines automated optimization with explicit interpretability. We investigate a human-directed workflow in which coding agents iteratively propose, implement, evaluate, diagnose, and eventually refine algorithms guided by simulation feedback and explicit correctness verification. We conducted two case studies and found that this workflow robustly outperformed any manually engineered solutions. On a challenging map in the 2024 League of Robot Runners competition, a two-day search discovered a policy that exceeds the stronger locally reproduced competition entry by 35.0% on the densest instance and generalizes to unseen map instances. In simulated real-world warehouses with irregular lanes, continuous robot geometry, and asynchronous motion, a week-long search discovered an entirely new class of multi-agent pathfinding algorithm that outperforms a calibrated proprietary solution in throughput by 58.9%. Under stated assumptions, we further prove that the new algorithm is collision-free and completes, in finite time, every accepted goal that is not withdrawn or replaced. Together, the studies show that policy search in code space powered by state-of-the-art coding agents offers a highly competitive path to building real engineering solutions that are both effective and analytically tractable.

为复杂的多智能体系统制定协调策略依赖于劳动密集型算法设计或不透明的特定任务强化学习。随着自主编码代理的最新进展，我们表明直接在代码空间中进行策略搜索提供了令人信服的第三条路径，它将自动优化与显式可解释性相结合。我们研究了一种以人为主导的工作流程，其中编码代理在模拟反馈和显式正确性验证的指导下迭代地提出、实施、评估、诊断并最终完善算法。我们进行了两个案例研究，发现该工作流程明显优于任何手动设计的解决方案。在 2024 年机器人跑者联盟竞赛的一张具有挑战性的地图上，为期两天的搜索发现了一种策略，该策略在最密集的实例上超出了更强的本地复制竞赛条目 35.0%，并且可以推广到未见过的地图实例。在具有不规则车道、连续机器人几何结构和异步运动的模拟现实仓库中，为期一周的搜索发现了一种全新的多代理寻路算法，其吞吐量比校准的专有解决方案高出 58.9%。在规定的假设下，我们进一步证明新算法是无碰撞的，并且在有限时间内完成了每个未撤回或替换的已接受目标。总之，这些研究表明，由最先进的编码代理支持的代码空间中的策略搜索为构建既有效又易于分析的实际工程解决方案提供了一条极具竞争力的途径。

## 2. EvoSkill v2: Fully Agentic Skill Evolution from Benchmark Adaptation to a Stateful Evolver / EvoSkill v2：从基准适应到有状态进化器的完全代理技能进化

**Date**: 2026-10-19 | **arXiv**: [2610.25931v1](http://arxiv.org/abs/2610.25931v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25931v1)

**Categories**: cs.AI, cs.CL, cs.LG

<details><summary><b>Abstract / 摘要</b></summary>

EvoSkill v2 is a three-agent system that edits the instructions (skills) an agent is given, leaving its model and harness intact. The user starts a run by describing a benchmark and supplying a grader, which a benchmark adaptor turns into a benchmark-specific plugin. A solver attempts the tasks, and an evolver reads the solver's training rollouts and rewrites the skills at each epoch. We implement the evolver as one stateful coding agent with a bash tool for the whole run, unlike the two most common designs among the skill optimizers we surveyed: a sequence of single model calls, as in SkillOpt, and an agent that starts afresh each round, as in SkillBoost. We also measure how much the solver's rollouts vary from one attempt to the next, give the evolver several attempts per training task, and accept every epoch's skills instead of selecting among them on noisy scores. With fine-grained ground truth, EvoSkill v2's skills raised the held-out pass rate above the stronger of SkillOpt and SkillBoost by 7.7 percentage points on SpreadsheetBench v2 and by 5.4 on $τ^3$-bench banking. In both benchmarks and both feedback settings, EvoSkill v2's evolver cost less per percentage point of held-out pass rate gained than either baseline's optimizer. EvoSkill v2 also enables a less capable model to improve its own skills, demonstrated by a gain of up to 21.5 percentage points in the $τ^3$-bench banking experiment where Claude Haiku 5.5 powers both solver and evolver.

EvoSkill v2 是一个三代理系统，可编辑代理给出的指令（技能），保持其模型和工具完好无损。用户通过描述基准并提供分级器来开始运行，基准适配器将其转变为特定于基准的插件。求解器尝试执行任务，进化器读取求解器的训练展示并重写每个时期的技能。我们将进化器实现为一个有状态编码代理，在整个运行过程中使用 bash 工具，这与我们调查的技能优化器中两种最常见的设计不同：一系列单一模型调用，如 SkillOpt 中，以及每轮重新启动的代理，如 SkillBoost 中。我们还测量求解器的推出从一次尝试到下一次尝试的差异有多大，为每个训练任务给予进化者多次尝试，并接受每个时期的技能，而不是在嘈杂的分数中进行选择。凭借细粒度的基本事实，EvoSkill v2 的技能在 SpreadsheetBench v2 上将保留通过率提高了 7.7 个百分点，在 $τ^3$ 基准银行上比 SkillOpt 和 SkillBoost 中的更强者提高了 5.4 个百分点。在两个基准和两个反馈设置中，EvoSkill v2 的进化器每获得一个百分点的保留通过率的成本都低于任一基准的优化器。 EvoSkill v2 还使能力较弱的模型能够提高自身技能，在 $τ^3$ 基准银行实验中，Claude Haiku 5.5 为求解器和进化器提供了高达 21.5 个百分点的提升，这证明了这一点。

## 3. Maestro: Agentic Formal Proof Development by Coordination / Maestro：通过协调开发代理形式证明

**Date**: 2026-10-19 | **arXiv**: [2610.25920v1](http://arxiv.org/abs/2610.25920v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25920v1)

**Categories**: cs.LG

<details><summary><b>Abstract / 摘要</b></summary>

Lean is increasingly used to verify mathematical proofs and software produced by LLM agents, but writing formal proofs remains hard. Existing prover systems take a divide-and-conquer approach that recursively decomposes hard proof obligations into easier lemmas and splits again any lemma that resists proof. However, a lemma can resist proof for different reasons, including insufficient guidance, a false statement, or a flaw in the decomposition that produced it. Existing systems cannot tell these apart as a failed attempt reports little beyond its failure, and responses are confined to the failing node without considering the rest of the proof or revising the plan above it. The system may thus keep decomposing obligations along a flawed proof direction until the budget runs out, causing the whole proof attempt to fail. We introduce Maestro, a Lean prover harness that handles failures through global coordination. Provers report why they failed, not just that they failed, and a coordinator that sees the whole proof chooses an appropriate response, such as guiding a stuck prover, correcting a false lemma, or retracting a flawed subtree and replanning it. The same harness extends to verified code synthesis, where a checked counterexample sends the code back for repair. We evaluate Maestro with four frontier LLMs on seven mathematics and three software verification benchmarks. It proves more targets than each model's native coding agent (Claude Code or Codex) on every benchmark the agent has not already saturated, with the largest gains on research-level mathematics. With Claude Opus 5, it discovers its own proofs of 34 of the 48 theorems in the June 2026 release of arXivLean, against 19 for the native agent. It also outperforms all published prover systems on every benchmark they share, solving 669/672 PutnamBench, 59/60 Lean-IMO-Bench, and 6/6 IMO 2026.

精益越来越多地用于验证数学证明和法学硕士代理生成的软件，但编写正式证明仍然很困难。现有的证明者系统采用分而治之的方法，将严格的证明义务递归地分解为更容易的引理，并再次拆分任何难以证明的引理。然而，引理可能会因为不同的原因而抵制证明，包括指导不足、错误陈述或产生引理的分解中的缺陷。现有系统无法区分这些，因为失败的尝试除了其失败之外几乎没有报告，并且响应仅限于失败的节点，而不考虑其余的证明或修改其之上的计划。因此，系统可能会沿着有缺陷的证明方向继续分解义务，直到预算耗尽，从而导致整个证明尝试失败。我们推出 Maestro，这是一种精益验证工具，可通过全局协调处理故障。证明者报告他们失败的原因，而不仅仅是他们失败了，看到整个证明的协调员会选择适当的响应，例如指导陷入困境的证明者，纠正错误的引理，或撤回有缺陷的子树并重新规划它。同样的工具可以扩展到经过验证的代码合成，其中经过检查的反例将代码发送回进行修复。我们通过四位前沿法学硕士在七个数学和三个软件验证基准上对 Maestro 进行评估。它在代理尚未饱和的每个基准上证明了比每个模型的本机编码代理（Claude Code 或 Codex）更多的目标，在研究级数学方面收益最大。借助 Claude Opus 5，它发现了 2026 年 6 月发布的 arXivLean 中 48 个定理中 34 个的自己的证明，而原生代理仅发现了 19 个。它还在所有共享的基准测试中优于所有已发布的验证系统，解决了 669/672 PutnamBench、59/60 Lean-IMO-Bench 和 6/6 IMO 2026。

</details>

## 4. LEAPS: Long-context Evaluation of Adaptive Pattern Learning and State Tracking / LEAPS：自适应模式学习和状态跟踪的长上下文评估

**Date**: 2026-10-19 | **arXiv**: [2610.25919v1](http://arxiv.org/abs/2610.25919v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25919v1)

**Categories**: cs.CL

<details><summary><b>Abstract / 摘要</b></summary>

Long-context language models (LCLMs) power agents that act over long trajectories, from improving a codebase to running research experiments to forecasters that condition on lengthy histories. These applications draw on three distinct long-context capabilities: recall, where the answer is a fact present in the context; state tracking, where the outcome can be computed by performing a series of transformations to a specified state; and pattern learning, where the goal is to make a prediction by sampling from a distribution inferred from many observations. Existing benchmarks primarily focus on the first capability. In this work, we introduce LEAPS (Long-context Evaluation of Adaptive Pattern learning and State tracking), a collection of 12 novel datasets, spanning agentic workflows, behavioral modeling, and forecasting of market and world events. By construction, LEAPS is resistant to data contamination, extends to millions of input tokens, and uses reliable metrics. We evaluate 30 API and open models from 8K to 512K input tokens. LEAPS distinguishes models that perform near perfectly on recall tasks, finding that such models' state tracking and pattern learning abilities can vary significantly and degrade much more dramatically with increasing input lengths--even for pattern learning, where more observations should make learning a theoretically easier task. Moreover, thinking models often underperform their base counterparts, exhausting their generation budget or oversimplifying the task. We hope LEAPS can guide the development of the next generation of LCLMs.

长上下文语言模型 (LCLM) 为在长轨迹上运行的代理提供动力，从改进代码库到运行研究实验，再到以漫长历史为条件的预测器。这些应用程序利用了三种不同的长上下文功能：回忆，答案是上下文中存在的事实；状态跟踪，可以通过对指定状态执行一系列转换来计算结果；模式学习，其目标是通过从许多观察推断的分布中进行采样来进行预测。现有的基准主要关注第一个能力。在这项工作中，我们介绍了 LEAPS（自适应模式学习和状态跟踪的长上下文评估），它是 12 个新颖数据集的集合，涵盖代理工作流程、行为建模以及市场和世界事件的预测。通过构建，LEAPS 可以抵抗数据污染，扩展到数百万个输入令牌，并使用可靠的指标。我们评估了 30 个 API 和开放模型，从 8K 到 512K 输入令牌。 LEAPS 区分了在回忆任务上表现近乎完美的模型，发现此类模型的状态跟踪和模式学习能力可能会发生显着变化，并且随着输入长度的增加而显着下降——即使对于模式学习来说，更多的观察应该会使学习在理论上成为一项更容易的任务。此外，思维模型往往表现不佳，耗尽其生成预算或过于简化任务。我们希望LEAPS能够指导下一代LCLM的发展。

</details>

## 5. InteractAgent: Agentic Human Motion Interaction with Memory-Augmented Reflection / InteractAgent：具有记忆增强反射功能的代理人体运动交互

**Date**: 2026-10-19 | **arXiv**: [2610.25649v1](http://arxiv.org/abs/2610.25649v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25649v1)

**Categories**: cs.RO, cs.CV

**Code**: https://github.com/AIGeeksGroup/InteractAgent.

<details><summary><b>Abstract / 摘要</b></summary>

Long-horizon human-scene interaction requires coordinated spatial reasoning, physical feasibility, and the ability to recover from compounding execution errors. Text-driven motion models are largely scene-agnostic and lack closed-loop correction, while geometry-conditioned approaches depend on paired scene-motion training or explicit 3D preprocessing that limits generalization to novel layouts and open-vocabulary goals. We present InteractAgent, an agentic multimodal LLM system for long-horizon human-scene interaction that plans, executes, observes, and reflects in a closed loop, using a single MLLM as both planner and evaluator and a frozen MotionLLM as the executor. InteractAgent integrates Online Observation for step-wise recovery decisions (continue/redo/replan) and Memory-Augmented Reflection for multi-round plan refinement with adaptive stopping. On UniHSI, InteractAgent improves task success and reduces penetration compared with training-free baselines. Code: https://github.com/AIGeeksGroup/InteractAgent.

长视野人景交互需要协调的空间推理、物理可行性以及从复合执行错误中恢复的能力。文本驱动的运动模型在很大程度上与场景无关，并且缺乏闭环校正，而几何条件方法依赖于配对场景运动训练或显式 3D 预处理，这限制了对新颖布局和开放词汇目标的泛化。我们提出了 InteractAgent，这是一个用于长视野人场景交互的代理多模态 LLM 系统，它在闭环中计划、执行、观察和反映，使用单个 MLLM 作为计划器和评估器，并使用冻结的 MotionLLM 作为执行器。 InteractAgent 集成了用于逐步恢复决策（继续/重做/重新计划）的在线观察和用于通过自适应停止进行多轮计划细化的内存增强反射。在 UniHSI 上，与免培训基线相比，InteractAgent 提高了任务成功率并降低了渗透率。代码：https://github.com/AIGeeksGroup/InteractAgent。

## 6. Zephyrus-R1: Agentic Reinforcement Learning for Weather Reporting / Zephyrus-R1：用于天气预报的代理强化学习

**Date**: 2026-10-19 | **arXiv**: [2610.25625v1](http://arxiv.org/abs/2610.25625v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25625v1)

**Categories**: cs.LG

<details><summary><b>Abstract / 摘要</b></summary>

Reinforcement learning (RL) has emerged as a key method for training AI models in scientific applications, but RL remains difficult when outputs cannot easily be verified against a known ground-truth answer. Natural-language weather forecast reports are one such domain: they translate atmospheric data into assessments of weather evolution, hazards, and uncertainty for both the general public and key decision-makers. Unlike numerical weather-analysis questions, they admit many valid outputs, which limits deterministic verification. To address this, we develop Zephyrus-R1, a practical framework for RL on scientific weather forecast reporting. We focus on three key components of the agentic RL pipeline: reward design, curriculum learning, and an analysis of human-expert alignment. To encourage both report legibility and factual accuracy, we design a reward function that combines a meteorological rubric with bidirectional claim entailment, both evaluated against National Weather Service reference reports. Our framework optimizes this reward in a simulated tool-calling environment, enabling vision-language agents to gather and analyze forecast evidence across regions and lead times before producing a report. We use annotations from three meteorologists to audit the claim labels produced by our LLM judges. Finally, a curriculum helps small models first develop tool use and scientific reasoning through RL on verifiable weather-analysis questions, then optimize the open-ended report reward. After training Qwen3.5-4B with Zephyrus-R1, we improve the mean across six judge-metric scores by 26% over the base model and achieve results competitive with frontier open-weight models. For Qwen3.8-27B, we improve the same mean by 13% over the base model, by 6.7% over Kimi-K3, and by 2.7% over GPT-5.6-Luna.

强化学习 (RL) 已成为在科学应用中训练人工智能模型的关键方法，但当输出无法轻松地根据已知的真实答案进行验证时，强化学习仍然很困难。自然语言天气预报报告就是这样的领域之一：它们将大气数据转化为对公众和关键决策者的天气演变、灾害和不确定性的评估。与数值天气分析问题不同，它们承认许多有效的输出，这限制了确定性验证。为了解决这个问题，我们开发了 Zephyrus-R1，这是科学天气预报报告强化学习的实用框架。我们专注于代理强化学习流程的三个关键组成部分：奖励设计、课程学习和人类专家一致性分析。为了提高报告的可读性和事实准确性，我们设计了一个奖励函数，将气象标题与双向索赔蕴含相结合，两者都根据国家气象局参考报告进行评估。我们的框架在模拟的工具调用环境中优化了这种奖励，使视觉语言代理能够在生成报告之前收集和分析跨区域和交付时间的预测证据。我们使用三位气象学家的注释来审核法学硕士法官制作的索赔标签。最后，课程首先帮助小型模型通过强化学习针对可验证的天气分析问题开发工具使用和科学推理，然后优化开放式报告奖励。使用 Zephyrus-R1 训练 Qwen3.5-4B 后，我们将六个判断指标得分的平均值比基本模型提高了 26%，并取得了与前沿开放权重模型相媲美的结果。对于 Qwen3.8-27B，我们将相同的平均值比基本模型提高了 13%，比 Kimi-K3 提高了 6.7%，比 GPT-5.6-Luna 提高了 2.7%。

## 7. Weighted State Souping for Efficient Long-Context Retrieval / 用于高效长上下文检索的加权状态汤

**Date**: 2026-10-19 | **arXiv**: [2610.25621v1](http://arxiv.org/abs/2610.25621v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25621v1)

**Categories**: cs.LG, cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

State space models (SSMs) combine fast inference and fixed state size with competitive language-modeling performance. Recently, state souping has been proposed as a procedure whereby an SSM independently encodes chunks of tokens like documents, tool definitions, or memory records. The resulting state encodings may be cached and recombined to cheaply construct a context for downstream queries. However, both state souping and vanilla SSMs deteriorate on long, crowded contexts, limiting their utility for long-horizon domains. To address this issue, we propose weighted state souping, a simple method that learns query-dependent weights for composing cached states. The resulting models improve long-context performance substantially across both single- and multi-hop document question answering, needle-in-a-haystack retrieval, variable tracking, and tool use. Our method can be further adapted into an efficient sparse variant, yielding near-constant encoding cost with respect to context length while preserving (and sometimes improving) performance. We also present simple theoretical arguments that illustrate why souping works and when it may fail, and discuss informally the advantages of weighted souping. Weighted state souping thus combines reusable context representations with selective retrieval, offering an efficient approach to language modeling over large collections of documents, tools, and other forms of structured context that increasingly dominate modern agentic workloads.

状态空间模型 (SSM) 将快速推理和固定状态大小与具有竞争力的语言建模性能相结合。最近，状态汤已被提议作为一种过程，SSM 通过该过程独立地编码文档、工具定义或内存记录等标记块。所得到的状态编码可以被缓存并重新组合，以廉价地构建用于下游查询的上下文。然而，状态汤和普通 SSM 在长而拥挤的环境中都会恶化，限制了它们在长范围领域的实用性。为了解决这个问题，我们提出了加权状态汤，这是一种学习与查询相关的权重来组成缓存状态的简单方法。由此产生的模型大大提高了单跳和多跳文档问答、大海捞针检索、变量跟踪和工具使用的长上下文性能。我们的方法可以进一步适应高效的稀疏变体，产生相对于上下文长度接近恒定的编码成本，同时保持（有时提高）性能。我们还提出了简单的理论论证，说明汤汤为何有效以及何时可能失败，并非正式地讨论了加权汤汤的优点。因此，加权状态汤将可重用的上下文表示与选择性检索结​​合起来，提供了一种对大量文档、工具和其他形式的结构化上下文进行语言建模的有效方法，这些文档、工具和其他形式的结构化上下文日益主导现代代理工作负载。

## 8. Auditing Tool Traces in Agentic LLMs: Source Localization and Counterfactual Dependence Testing / 代理法学硕士中的审计工具跟踪：源本地化和反事实依赖测试

**Date**: 2026-10-18 | **arXiv**: [2610.25540v1](http://arxiv.org/abs/2610.25540v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.25540v1)

**Categories**: cs.AI, cs.CL

<details><summary><b>Abstract / 摘要</b></summary>

Agentic LLMs increasingly support scientific prediction by grounding decisions in external evidence. In biology, they promise accurate, interpretable predictions for important problems by integrating complex experimental and computational evidence. However, serialized tool results can contain hidden label shortcuts, such as dataset identifiers or template artifacts, that create apparent success without biological reasoning. To address this risk, we introduce a two-stage audit. Stage 1, Per-Tool TF-IDF Decomposition (PT2D), localizes label-predictive patterns to individual tool results while avoiding signal dilution in the concatenated tool trace. Stage 2, Token-Class Redaction, counterfactually tests whether the frozen LLM depends on the localized shortcut. We apply this audit to TCR-pMHC binding, where tool augmentation substantially outperforms a no-evidence baseline. At face value, this suggests that the LLM has learned to use scientific evidence. The audit overturns this interpretation: PT2D localizes the strongest signal to identifiers in one tool result, and redacting them reduces performance to chance. These findings show how hidden label shortcuts can masquerade as scientific reasoning or discovery, motivating source-level audits before benchmark gains are trusted.

## 21. Bellman Language Models: Solving the Recurring Decisions of LLM Agents / Bellman 语言模型：解决 LLM 代理的重复决策

<details><summary><b>Abstract / 摘要</b></summary>

It reads each conversation into discrete states and estimates the probability of each outcome and the cost of each move, until no new states appear and the probabilities stop changing. The solution runs as a controller around the model, sending moves whose content is fixed in the state, such as a tool call or a templated reply, and any state it hasn't seen is sent back to the LLM. Against standard message passing, accuracy in peer groups rose by 39-77 percentage points across three benchmarks, and tokens per run fell by 10-46%. Gains held across seven open models spanning four to thirty-two billion parameters and two commercial models, in groups up to sixty-four agents, and across multi-agent architectures including peer-to-peer, orchestrator-worker, and multilevel hierarchical organizations. These findings support a scalable design pattern for more accurate and token-efficient multi-agent reasoning.

多代理系统有望通过汇集任何单个代理无法访问的信息来解决问题。检索和工具的使用可以跨代理分发此信息，从而使通信对于协作至关重要。一个核心挑战是随着消息的积累，在每个代理的上下文中保持关键证据可见。重复的信息可能会排除罕见的、决定性的证据。皮层回路模型提出了解决这种不平衡的原则：抑制可以选择性地抑制共享输入，同时保持对较弱信号的敏感性。我们将这一原理应用于抑制性消息传递，这是一种无需训练的通信路由器，可以为每个证据句子和接收者分别取消冗余证据。每一轮，它都会转发特工消息中重申的证据句子，每个最多一次传递给自己证据缺乏的接收者，并排除发送者的推理和答案。与标准消息传递相比，在三个基准测试中，同行群体的准确率提高了 39-77 个百分点，而每次运行的代币数量下降了 10-46%。跨越 4 至 320 亿个参数的 7 个开放模型和两个商业模型、最多 64 个代理的组以及跨多代理架构（包括对等、编排工作人员和多级分层组织）都取得了收益。这些发现支持可扩展的设计模式，以实现更准确和令牌效率更高的多代理推理。

</details>

## 24. DiffuPlan: Editable Planning State for Diffusion Language Model Agents / DiffuPlan：扩散语言模型代理的可编辑规划状态

**Date**: 2026-10-17 | **arXiv**: [2610.24717v1](http://arxiv.org/abs/2610.24717v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.24717v1)

**Categories**: cs.CL, cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

Diffusion language models (dLLMs) are emerging as an alternative to autoregressive (AR) language models, yet dLLM agents largely inherit an interaction protocol designed for AR generation: once intermediate state is written, later observations can only be incorporated by appending more text. This is a poor match to a defining capability of dLLMs -- reconstructing earlier text conditioned on context that appears both before and after it. We ask whether this capability can support a different agent-state paradigm in which intermediate planning state is directly revisable as evidence arrives. We introduce DiffuPlan, a diffusion search agent that maintains a single editable planning state and reconstructs only the affected steps when later evidence resolves an entity or changes the search route. To support variable-length revisions, we introduce Expansion-Partition Marginalization (EPM), which marginalizes over equivalent expansion paths. We further adapt diffusion trajectory RL to multi-turn search. Across four multi-hop QA benchmarks, DiffuPlan achieves 50.24 average F1, outperforming strong AR search agents. More importantly, under identical data and training, editable planning state improves the diffusion agent by 2.44 F1 versus only 0.47 for its AR source model. These results show that dLLMs need not imitate append-only AR agents: revising committed state is a distinct agentic advantage.

扩散语言模型 (dLLM) 正在成为自回归 (AR) 语言模型的替代方案，但 dLLM 代理在很大程度上继承了为 AR 生成而设计的交互协议：一旦写入中间状态，以后的观察结果只能通过附加更多文本来合并。这与 dLLM 的定义能力不太匹配——根据出现在其之前和之后的上下文来重建早期文本。我们询问这种能力是否可以支持不同的代理状态范式，其中中间计划状态可以在证据到达时直接修改。我们引入了 DiffuPlan，一种扩散搜索代理，它维护单个可编辑的规划状态，并在后来的证据解析实体或更改搜索路线时仅重建受影响的步骤。为了支持可变长度修订，我们引入了扩展分区边缘化（EPM），它边缘化了等效的扩展路径。我们进一步将扩散轨迹 RL 应用于多轮搜索。在四个多跳 QA 基准测试中，DiffuPlan 的平均 F1 达到 50.24，优于强大的 AR 搜索代理。更重要的是，在相同的数据和训练下，可编辑规划状态将扩散代理的 F1 提高了 2.44，而 AR 源模型仅提高了 0.47。这些结果表明 dLLM 不需要模仿仅附加 AR 代理：修改提交状态是一个明显的代理优势。

## 25. Muse Glimmer 30B: An On-Device Agentic Model / Muse Glimmer 30B：设备上代理模型

**Date**: 2026-10-17 | **arXiv**: [2610.24628v1](http://arxiv.org/abs/2610.24628v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.24628v1)

**Categories**: cs.CL, cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

We introduce Muse Glimmer, an open-source 30B parameter causal language model with perception encoder, purpose-built for autonomous agentic tasks on consumer hardware. Muse Glimmer integrates multi-step reasoning, reliable tool use and failure recovery into a single model that runs locally on consumer devices without requiring cloud infrastructure. The model accepts text and image inputs and produces text outputs, was trained on data from over a hundred languages, and is quantized to approximately 4-bit precision for efficient single-GPU inference. Muse Glimmer achieves state-of-the-art performance for its size class on agentic benchmarks, setting a new standard compared to the models of its size: Gemma4-31B and Qwen3.6-27B on tool use, multi-step planning, and agentic task completion. We release the model under the Apache 2.0 license to foster open-source development of capable, safe, local AI agents.

我们推出 Muse Glimmer，这是一种带有感知编码器的开源 30B 参数因果语言模型，专为消费类硬件上的自主代理任务而构建。 Muse Glimmer 将多步骤推理、可靠的工具使用和故障恢复集成到一个模型中，该模型可以在消费设备上本地运行，无需云基础设施。该模型接受文本和图像输入并生成文本输出，接受了超过 100 种语言的数据训练，并量化至大约 4 位精度，以实现高效的单 GPU 推理。 Muse Glimmer 在代理基准测试中实现了其尺寸级别的最先进性能，与同尺寸模型（Gemma4-31B 和 Qwen3.6-27B）相比，在工具使用、多步骤规划和代理任务完成方面树立了新标准。我们在 Apache 2.0 许可证下发布该模型，以促进功能强大、安全的本地 AI 代理的开源开发。
