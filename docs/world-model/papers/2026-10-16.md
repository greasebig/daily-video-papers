## 1. Learning Intrinsic Dynamics in Latent World Models / 在潜在世界模型中学习内在动力学

**Date**: 2026-10-15 | **arXiv**: [2610.21612v1](http://arxiv.org/abs/2610.21612v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.21612v1)

**Categories**: cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

Learning intrinsic dynamics---the relationship between actions and their consequences---is essential for world models. However, visual variations unrelated to the underlying control process can obscure this relationship in learned representations. We investigate the connection between action predictability, defined as the ability to reconstruct an action from consecutive latent states, and the preservation of intrinsic dynamics. Our central hypothesis is that encouraging action predictability discourages representations from discarding the distinctions between different actions and their consequences. We provide two complementary forms of evidence for this connection. Theoretically, we derive a positive lower bound on squared inverse prediction error when the encoder merges distinguishable outcomes of different actions from the same state and appearance, and show that forward prediction can still be exact on those transitions. Empirically, controlled appearance-diversity comparisons, supervision interventions, and latent probes support the role of action prediction in preserving control-relevant transition information. We instantiate action predictability with Concat IDM, which predicts actions from concatenated latent states and updates the shared encoder using action labels already available in offline trajectories, without changing the test-time planner. Across three independent training runs on Push-T with 24 appearances, Concat IDM increases planning success from 9.1% to 77.2%; its paired improvement is 52.9 percentage points larger than that observed with a single appearance. Together, these findings support action predictability as an inductive bias toward intrinsic dynamics and demonstrate the practical benefits of Concat IDM for latent planning under visual diversity.

## 2. From Optical Flow to Safety: Visual Safety Certification via Scale-Free Relative Motion / 从光流到安全：通过无标度相对运动进行视觉安全认证

**Date**: 2026-10-15 | **arXiv**: [2610.21374v1](http://arxiv.org/abs/2610.21374v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.21374v1)

**Categories**: cs.RO, eess.SY

<details><summary><b>Abstract / 摘要</b></summary>

Safe autonomous navigation using monocular vision remains challenging because explicit obstacle states are not directly observable. This letter introduces a visual safety-certification paradigm that uses scale-free, depth-normalized relative motion encoded by monocular optical flow as the representation for collision-risk certification, without reconstructing obstacle position, velocity, geometry, or a metric world model. Unlike conventional optical-flow-based navigation approaches that rely on image motion to shape avoidance behavior, the proposed framework directly encodes collision-cone geometry and safety constraints in this relative-motion representation. An online Concurrent Learning observer estimates the normalized relative velocity and provides a computable estimation-error bound. This uncertainty is propagated into the collision cone through angular inflation and a monocular robot-footprint margin, yielding a Robust Vision-Based Collision Cone Control Barrier Function (RV-C$^3$BF). An optimal-decay CBF quadratic program minimally modifies the nominal control input to enforce the resulting robust safety constraint under the stated assumptions. Extensive simulation and real-world experiments on a TurtleBot3 in cluttered environments with static and dynamic obstacles demonstrate collision avoidance using only monocular vision and onboard proprioception, with the estimation-error bound containing the measured error in $98.3\%$ of simulation samples and the robot achieving collision-free navigation in $93$ of $100$ real-world trials.

使用单目视觉的安全自主导航仍然具有挑战性，因为无法直接观察到明显的障碍物状态。 这封信介绍了一种视觉安全认证范例，该范例使用由单目光流编码的无标度、深度归一化的相对运动作为碰撞风险认证的表示，而无需重建障碍物位置、速度、几何形状或度量世界模型。 与依赖图像运动来形状规避行为的传统的基于光流的导航方法不同，所提出的框架在这种相对运动表示中直接编码碰撞锥几何和安全约束。 在线并发学习观察者估计归一化相对速度并提供可计算的估计误差界限。 这种不确定性通过角膨胀和单目机器人足迹裕度传播到碰撞锥中，产生基于强大视觉的碰撞锥控制屏障函数（ RV-C $ ^ 3 $ BF ）。 最优衰减CBF二次程序对标称控制输入进行最小修改，以在所述假设下执行由此产生的鲁棒安全约束。 在带有静态和动态障碍物的混乱环境中对TurtleBot3进行了广泛的模拟和真实世界实验，证明了仅使用单目视觉和机载本体感知来避免碰撞，估计误差范围包含$ 98.3\ % $的模拟样本和机器人中的测量误差

## 4. Mallea: Building, Steering, and Memorizing Worlds with Coding Agent / Mallea ：使用编码代理构建、指导和记忆世界

**Date**: 2026-10-15 | **arXiv**: [2610.21283v1](http://arxiv.org/abs/2610.21283v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.21283v1)

**Categories**: cs.AI, cs.CV

<details><summary><b>Abstract / 摘要</b></summary>

Code world models represent world dynamics through explicit state and executable rules. We investigate how to coordinate object representations, behavioral revisions, and visual memory within this formulation. We present Mallea, a system for building, steering, and memorizing worlds from text. A coding agent infers object interaction requirements from the prompt and jointly plans object structure, properties, and rules, favoring compact representations that support those requirements. The world evolves under the planned rules; optional user actions steer it, while text requests can edit properties or extend capabilities with unaffected state preserved. Object texture memory retains reusable appearance only for whitebox-defined objects and adapts it as those objects change. The program advances world state, while a generative renderer combines current structure with remembered appearance. By organizing construction, intervention, and memory around the same objects, Mallea conditions subsequent observations on the latest state and compatible appearance. Project page: https://lxycopper.github.io/Mallea.

代码世界模型通过显式状态和可执行规则表示世界动态。 我们研究如何在这个公式中协调对象表示、行为修正和视觉记忆。 我们展示了Mallea ，这是一个从文本中构建、引导和记忆世界的系统。 编码代理从提示中推断对象交互要求，并联合规划对象结构、属性和规则，有利于支持这些要求的紧凑表示。 世界在计划的规则下发展；可选的用户操作引导它，而文本请求可以编辑属性或扩展功能，并保留不受影响的状态。 对象纹理内存仅保留白盒定义的对象的可重用外观，并在这些对象发生变化时对其进行调整。 该程序推进世界状态，而生成渲染器将当前结构与记忆中的外观相结合。 通过围绕相同的物体组织构造、干预和记忆， Mallea为后续观察的最新状态和兼容外观提供了条件。 项目页面： https://lxycopper.github.io/Mallea。

## 5. When Reality Outpaces Cognition: A New Scaling Principle for Reliable Intelligence / 当现实超越认知：可靠智能的新扩展原则

**Date**: 2026-10-14 | **arXiv**: [2610.20764v1](http://arxiv.org/abs/2610.20764v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.20764v1)

**Categories**: cs.AI, cs.LG, cs.RO

<details><summary><b>Abstract / 摘要</b></summary>

This paper challenges the understanding capabilities of existing AI paradigms and emerging world models by asking a fundamental question: How quickly can reality change before an intelligent system can no longer reliably perceive, reason, and act? We formulate this as a theory- and model-agnostic challenge in which systems must infer reliable actions for increasingly distant future states across a growing observation--reality gap. We operationalize this challenge through the effective Speed of Coherent Cognition (\(S_C^{\mathrm{eff}}\)), defined as the highest tested Speed of Reality (\(S_R\)) through which a system continuously satisfies a predefined behavioural reliability criterion from baseline. As a proof of concept, reinforcement-learning agents are trained at the baseline \(S_R\) and evaluated, without retraining, as \(S_R\) is increased by up to \(50\times\) while computational resources remain fixed. We compare Transformer and gated-MLP baselines with \(Co^4\), an architecture inspired by cellular mechanisms implicated in conscious processing and awake thought. Across the tested scenarios, \(Co^4\) achieves substantially higher \(S_C^{\mathrm{eff}}\) than the baselines, motivating \(S_C^{\mathrm{eff}}\) as a new benchmark and the scaling of coherent cognition as a principle for reliable AI.

本文通过提出一个基本问题来挑战现有人工智能范式和新兴世界模型的理解能力：在智能系统无法再可靠地感知、推理和采取行动之前，现实变化的速度有多快？ 我们将其描述为一个与理论和模型无关的挑战，其中系统必须在不断增长的观察现实差距中为日益遥远的未来状态推断出可靠的行动。 我们通过有效的相干认知速度（\ (S_C ^ {\ mathrm {eff}}\) ）来实现这一挑战，该速度被定义为经测试的最高现实速度（\ (S_R\) ） ，通过该速度，系统从基线开始持续满足预定义的行为可靠性标准。 作为概念证明，强化学习代理在基线\ (S_R\)进行培训，并在不进行再培训的情况下进行评估，因为\ (S_R\)最多增加\ (50\倍\) ，而计算资源保持不变。 我们将Transformer和门控-MLP基线与\ (Co ^ 4\)进行比较，\ (Co ^ 4\)是一种受有意识处理和清醒思维所涉及的细胞机制启发的架构。 在测试的场景中，\ (Co ^ 4\)实现了比基线高得多的\ (S_C ^ {\ mathrm {eff}}\) ，激励\ (S_C ^ {\ mathrm {eff}}\)作为新的基准，并将连贯认知作为可靠AI的原则进行扩展。

## 6. SafeDriveVLA: Navigation-Conditioned World Model Dreaming for Conflict-Aware End-to-End Autonomous Driving / SafeDriveVLA ：梦想冲突感知端到端自动驾驶的导航条件世界模型

**Date**: 2026-10-14 | **arXiv**: [2610.20609v1](http://arxiv.org/abs/2610.20609v1) | **PDF**: [Link](http://arxiv.org/pdf/2610.20609v1)

**Categories**: cs.RO

<details><summary><b>Abstract / 摘要</b></summary>

Vision-Language-Action (VLA) models are gaining attention in autonomous driving, inheriting commonsense priors from large language models (LLMs) and widening the navigation interface from a fixed command set to free-form natural-language instructions. However, this open-ended interface exposes a new vulnerability surface: an inattentive driver may issue instructions that are unsafe given the current scene, and a malicious user may issue dangerous ones on purpose. We present the first benchmark suite that evaluates navigation following and conflict awareness together, along with adversarial robustness. Existing VLAs fall short on both: SimLingo completes no language-instructed lane change in closed loop, and all models degrade sharply under conflicting signals. We propose SafeDriveVLA, the first driving VLA that (1) explicitly predicts a three-level navigation-compliance mode to decouple conflict reasoning from action generation, and (2) uses navigation-conditioned world model dreaming to inform this prediction. Unlike prior world models that roll out expert or planned actions, ours dreams of strictly following the navigation signal, showing when following is safe. SafeDriveVLA reaches 88.16 Driving Score (DS) and 68.64% Success Rate (SR) on Bench2Drive, lifts closed-loop language following by 49.3% and reduces collisions under unsafe instructions from 60 to 38 compared to the best SimLingo variant. Video demonstrations are available on our project page.
